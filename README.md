# Diabrogue

## Project Overview
Diabrogue is an innovative roguelike game that provides players with a unique dungeon-crawling experience. The game is built using modern technologies and incorporates various gameplay mechanics, including combat, exploration, and item collection.

## Features
- Procedurally generated dungeons
- Turn-based combat system
- Diverse character classes and abilities
- Item crafting and inventory management
- Enemy AI with different difficulty levels

## Getting Started
### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/coolking70/diabrogue.git
   ```
2. Navigate into the project directory:
   ```bash
   cd diabrogue
   ```
3. Install the required dependencies:
   ```bash
   npm install
   ```

### Running the Game
To start the game, run:
```bash
npm start
```
